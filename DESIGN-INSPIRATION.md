## 📋 Design Review Checklist

Sebelum diteruskan ke development:

- [ ] Brand guidelines (color, typography) disetujui
- [ ] All key pages didesain
- [ ] Responsive breakpoints verified (mobile, tablet, desktop)
- [ ] Accessibility checked (color contrast, readability)
- [ ] Interactive states defined (hover, focus, active)
- [ ] Animations/transitions specified
- [ ] Component library created
- [ ] Design system documented
- [ ] Handoff to development team prepared
- [ ] Figma/design files organized & shared

---

## 🚀 Design-to-Code Workflow

1. **Export dari Figma**
   - Use Figma Dev Mode for developer handoff
   - Export assets (images, icons)
   - Generate CSS specs

2. **Create Tailwind Components**
   - Match design specifications exactly
   - Use design tokens (colors, spacing)
   - Maintain consistency

3. **Quality Assurance**
   - Compare pixel-perfect with design
   - Test responsive breakpoints
   - Verify animations

4. **Iterate & Refine**
   - Designer reviews implementation
   - Make adjustments as needed
   - Document any deviations

**Tips Tambahan:**

- 💡 Jika menggunakan AI art generator, tambahkan detail:
  - Style: "modern, professional, clean, minimalist"
  - Quality: "--q 2" untuk Midjourney = lebih berkualitas
  - Aspect ratio: "--ar 16:9" untuk landscape, "--ar 9:16" untuk portrait
  
- 📸 Untuk foto stok, pilih yang:
  - Sudah bebas lisensi (CC0, Unsplash, Pexels)
  - Sesuai dengan brand identity
  - High resolution (minimal 1920px width untuk web)
  - Diverse representation (guru & siswa beragam)

- 🎨 Consistency adalah kunci:
  - Gunakan color palette yang sama di semua aset
  - Typography konsisten
  - Component size & spacing konsisten
